## Surgical Planning for Long Bone Fracture Reduction

1. [op=user_choice] In the "Input volume" section, select the CT volume for processing.
2. [op=branch_op] If ROI crop of the volume is required, check the "Crop the input volume to an ROI" box. If not, jump to step 7.
3. [op=slicer_op] In the "Markups" module, click "ROI" to create an empty MarkupsROI node named "Longbone_Region".
4. [op=user_interaction] Manually click and adjust on the Slice views to create the ROI for the "Longbone_Region".
5. [op=user_choice] In the "ROI (Drawn in Markups)" section, select the MarkupsROI node.
6. [op=extension_op] Click the "Cofrim crop" button.
7. [op=slicer_op] In the "Segment Editor" module, create a new segmentation named "Reference_Segmentation".
8. [op=slicer_op] In the "Segment Editor" module, click the "Add" button and rename the segment to "Reference_Segment" under "Reference_Segmentation", and set its color to Sage Green.
9. [op=slicer_op] In the "Segment Editor" module, click the "Threshold" button.
10. [op=user_choice] In the "Segment Editor" module, adjust the threshold slider to set the segmentation range.
11. [op=slicer_op] In the "Segment Editor" module, click the "Apply" button.
12. [op=slicer_op] In the "Segment Editor" module, click the "Islands" button.
13. [op=slicer_op] In the "Segment Editor" module, select the "Keep selected island" option.
14. [op=user_interaction] In the 2D view, click to select the reference part.
15. [op=slicer_op] In the "Segment Editor" module, create a new segmentation named "Moving_Segmentation".
16. [op=slicer_op] In the "Segment Editor" module, click the "Add" button and rename the segment to "Moving_Segment" under "Moving_Segmentation", and set its color to Cyan.
17. [op=slicer_op] In the "Segment Editor" module, click the "Threshold" button.
18. [op=user_choice] In the "Segment Editor" module, adjust the threshold slider to set the segmentation range. The default value matches the threshold set in Step 10.
19. [op=slicer_op] In the "Segment Editor" module, click the "Apply" button.
20. [op=slicer_op] In the "Segment Editor" module, click the "Islands" button.
21. [op=slicer_op] In the "Segment Editor" module, select the "Keep selected island" option.
22. [op=user_interaction] In the 2D view, click to select the moving part.
23. [op=user_choice] In the "Reference segmentation (fixed)" section, select the reference segmentation node.
24. [op=extension_op] Click the "3D Reconstruction (reference)" button.
25. [op=user_choice] In the "Moving segmentation (repositioned)" section, select the moving segmentation node.
26. [op=extension_op] Click the "3D Reconstruction (moving)" button.
27. [op=extension_op] Click the "Detect fracture surfaces" button.
28. [op=extension_op] Click the "Initialize registration" button.
29. [op=user_interaction] Manually adjust the rotation and displacement of the moving part.
30. [op=extension_op] Click the "Reduction planning" button.
